Set up automatic switching with keywords

Keywords are optional. They match whole words in console URLs, so “prod” matches “my-prod-queue” but not “nonprod”. Leave them blank for manual switching. Conflicting matches always ask you to choose.

Redirect Behavior

AccountHop switches automatically when a link contains one account ID or matches one keyword rule. Suggestions and conflicting matches always ask you to choose.
